# 👻 Repo Séance

**The ghost of a forgotten codebase.**

Repo Séance is an experimental developer tool designed to investigate forgotten Git repositories and help developers rediscover the stories hidden in their code.

What if a codebase could tell you why it was created, what its developers were trying to achieve, and which unfinished ideas deserve another chance?

That's the idea behind Repo Séance.

## 💡 The Vision

Repo Séance aims to use open-weight AI and Git repository analysis to:

- Investigate repository commit history.
- Identify unfinished TODOs and abandoned development threads.
- Reconstruct the context behind forgotten code.
- Generate an AI-powered Ghost Report.
- Suggest practical steps to revive neglected projects.

## 🛠️ Technology

Planned technology stack:

- Node.js
- TypeScript
- pnpm workspaces
- Git CLI
- Ollama
- Gemma through local inference
- React and Vite for the future dashboard

## 🔭 Development Roadmap

1. Build Git repository analysis.
2. Integrate a local open-weight AI model.
3. Generate evidence-based repository insights.
4. Build an interactive developer dashboard.
5. Add testing and documentation.

## 🔐 Why Open-Source AI?

The long-term goal is to keep repository analysis local, giving developers more control over their code and the models interpreting it.

Local inference should allow developers to experiment with different models without depending on a proprietary hosted AI API.
